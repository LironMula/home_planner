# Home Floor Planner

A standalone browser app for planning a home layout in 2D and viewing it in 3D.

Open `index.html` in a browser to use the app.

Architect designs are ordinary saved projects under `plans/`. In the app, use
**Load GitHub** and select `architect-alt-3`, `architect-alt-4-sheet-1`,
`architect-alt-4-sheet-11`, or `architect-alt-5`.
